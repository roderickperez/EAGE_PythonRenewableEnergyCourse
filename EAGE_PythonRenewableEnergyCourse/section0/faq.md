# Frequently asked questions

## Do I need previous Python experience?
No. Work through Sections 1–3 first. Basic algebra and unit conversions are enough to start.

## Why does my result differ?
Check units, time step, rounding, random seed, package versions and earlier cells. Use `np.isclose` for floating-point comparisons.

## Where are the solutions?
Each workbook exercise has a collapsed Solution dropdown. Try the prompt, reveal the steps, then hide them to retry unaided.

## Are the numbers real project data?
The workbook and portfolio use synthetic data. Eurostat examples use historical exports. Neither represents current project performance.

## Can I use these models for a real design?
They teach concepts and checks. Real design needs measurements, manufacturer curves, applicable standards, current costs, uncertainty analysis and specialist review.

## What should I read next?
Follow the [learning guide](../learningGuide.md) and [reference catalogue](../references.md). Each exercise includes its own reference.
