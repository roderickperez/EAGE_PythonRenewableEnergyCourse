# Frequently asked questions

## Do I need previous Python experience?
Prior Python experience is optional. The included [Python foundations lesson](python-foundations.md) covers the tools used later in the course. Familiarity with basic programming concepts, descriptive statistics, algebra and unit conversions helps.

## Why does my result differ?
Check units, time step, rounding, random seed, package versions and earlier cells. Use `np.isclose` with tolerances appropriate to the units and expected numerical error. [NumPy isclose](https://numpy.org/doc/stable/reference/generated/numpy.isclose.html).

## Where are the solutions?
Each workbook exercise has a collapsed Solution dropdown. Try the prompt, reveal the steps, then hide them to retry unaided.

## Are the numbers real project data?
The workbook and portfolio use synthetic data. The older Eurostat notebooks use historical exports; the new download tutorial supports both a live API request and an explicitly labelled snapshot. Neither represents current project performance.

## Can I use these models for a real design?
They teach concepts and checks. Real design needs measurements, manufacturer curves, applicable standards, current costs, uncertainty analysis and specialist review.

## What should I read next?
Follow the [learning guide](../learningGuide.md) and [reference catalogue](../references.md). Each exercise includes its own reference.
