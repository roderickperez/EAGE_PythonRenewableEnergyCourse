:::{admonition} Question 1
:class: note

**Hydroelectric Power Formula**

The power generated by a hydroelectric plant is given by:

$$P = \eta \rho g Q H$$

where:
- $\eta$ = turbine efficiency (dimensionless)
- $\rho$ = water density (1000 kg/m³)
- $g$ = gravitational acceleration (9.81 m/s²)
- $Q$ = volumetric flow rate (m³/s)
- $H$ = effective head (m)

Calculate the power output (in MW) for:
- $\eta = 0.90$, $Q = 150$ m³/s, $H = 45$ m.
:::

:::{admonition} Question 1 (Solution)
:class: tip, dropdown

Substituting the given values:

```{code-cell} python
eta = 0.90     # efficiency
rho = 1000     # kg/m³
g   = 9.81     # m/s²
Q   = 150      # m³/s
H   = 45       # m

P_W  = eta * rho * g * Q * H
P_MW = P_W / 1e6
print(f"Power output: {P_W:,.0f} W = {P_MW:.3f} MW")
```
:::

:::{admonition} Question 2
:class: note

**Energy Production**

A run-of-river hydro plant operates with:
- Power: $P = 12$ MW  
- Average capacity factor: 55 %  
- Operation: 8760 hours/year

Calculate the **annual energy production** in GWh.
:::

:::{admonition} Question 2 (Solution)
:class: tip, dropdown

Annual energy = P × capacity_factor × hours:

```{code-cell} python
P_MW             = 12      # MW
capacity_factor  = 0.55
hours_per_year   = 8760

energy_GWh = P_MW * capacity_factor * hours_per_year / 1000
print(f"Annual energy production: {energy_GWh:.2f} GWh")
```
:::

:::{admonition} Question 3
:class: note

**Head and Flow Rate Relationship**

For a fixed turbine efficiency ($\eta = 0.88$) and a head $H = 60$ m, compute the power output for each of the following flow rates (m³/s):

```python
flow_rates = [30, 60, 90, 120, 150]
```

Store the results in a list and print them formatted as MW.
:::

:::{admonition} Question 3 (Solution)
:class: tip, dropdown

We loop over flow rates and apply the power formula:

```{code-cell} python
eta = 0.88
rho = 1000
g   = 9.81
H   = 60

flow_rates = [30, 60, 90, 120, 150]
powers_MW = [eta * rho * g * Q * H / 1e6 for Q in flow_rates]

for Q, P in zip(flow_rates, powers_MW):
    print(f"Q = {Q:3d} m³/s  →  P = {P:.3f} MW")
```
:::

:::{admonition} Question 4
:class: note

**Efficiency Impact**

For a hydro plant with $Q = 100$ m³/s and $H = 80$ m, plot power output (MW) vs. turbine efficiency ranging from 0.50 to 0.99 (step 0.01).

Label the axes and add a title.
:::

:::{admonition} Question 4 (Solution)
:class: tip, dropdown

We use NumPy to create the efficiency range and Matplotlib to plot:

```{code-cell} python
import numpy as np
import matplotlib.pyplot as plt

rho = 1000
g   = 9.81
Q   = 100
H   = 80

eta_values = np.arange(0.50, 1.00, 0.01)
power_MW   = eta_values * rho * g * Q * H / 1e6

plt.figure(figsize=(7, 4))
plt.plot(eta_values, power_MW, color="royalblue", linewidth=2)
plt.xlabel("Turbine Efficiency (η)")
plt.ylabel("Power Output (MW)")
plt.title("Hydro Power Output vs. Turbine Efficiency")
plt.grid(True, linestyle="--", alpha=0.5)
plt.tight_layout()
plt.show()
```
:::

**Reservoir Potential Energy**

The potential energy stored in a reservoir is:

$$E = m g h$$

A reservoir contains $V = 5 \times 10^8$ m³ of water at an average head of $h = 55$ m.

1. Calculate the stored energy in Joules and in TWh.
2. If the plant efficiency is 90 %, what is the usable energy in TWh?
:::

:::{admonition} Question 5 (Solution)
:class: tip, dropdown

We first compute the mass from volume and density, then apply $E = mgh$:

```{code-cell} python
rho = 1000       # kg/m³
g   = 9.81       # m/s²
V   = 5e8        # m³
h   = 55         # m
eta = 0.90

mass    = rho * V          # kg
E_J     = mass * g * h     # Joules
E_TWh   = E_J / 3.6e15    # TWh (1 TWh = 3.6e15 J)
usable  = eta * E_TWh

print(f"Stored energy:  {E_J:.3e} J")
print(f"Stored energy:  {E_TWh:.4f} TWh")
print(f"Usable energy:  {usable:.4f} TWh  (η = {eta})")
```
:::
